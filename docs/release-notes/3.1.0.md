A free, offline scientific calculator for engineering students — graphing, equations, matrices,
complex numbers, calculus, statistics, finance and a programmer mode in one fast native app.

## What's new in 3.1.0

**Sheet** — switch Calculate to a sheet (History | Sheet, top right): one calculation per line, each
result beside it. `name = calculation` stores a value, and names can be longer than one letter
(`fc`, `ωn`, `u1`). `#` starts a comment. Change a value and every line below follows; the keypad
types into the sheet.

**File menu** — File ▾ in the top bar (and a File menu in the macOS menu bar):
- New, Open…, Save, Save as…: sheets are plain text `.calc` files (⌘N ⌘O ⌘S, Ctrl on Windows and Linux)
- **New from template**: RC Filter, Beam deflection, Vibration, RLC impedance, Measurement uncertainty
- **Export CSV…**: the sheet or history, the Table values, the Statistics data or the selected matrix

The sheet comes back as it was when the app is next opened. Settings shows where it is saved and
has a Clear sheet link; Edit ▸ Clear Sheet on macOS.

**Windows .msi installer** — Windows now gets a standard Windows Installer package with a Start-menu
entry and an entry in Settings ▸ Apps; a newer .msi replaces an older version in place.

Full history in [CHANGELOG.md](https://github.com/Tikitech01/scientific-calculator/blob/main/CHANGELOG.md).
